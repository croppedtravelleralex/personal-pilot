# antbrowser 路线图

本文件只记录阶段目标和里程碑，不记录执行细节。

## Now

### 1. 行为录制跨上下文与规模化增强

- 目标：在 P0/P2 与真实指纹 Chromium 基础 E2E 已通过的基础上，补齐复杂页面和超大录制能力。
- 预期产出：新标签/跨 target/iframe 录制策略、超大录制 manifest/index、裁剪/导入导出/复制模板/回放进度/失败重试入口均已完成；后续只保留内部滚动容器和真实业务页面回归样例。
- 进入条件：基础录制/回放 E2E、后端全量测试、前端生产构建均已通过。
- 当前状态：P2 已落地；P3 的 summary list、详情分页、搜索 debounce、敏感输入脱敏、产品化工具入口、真实 E2E、manifest/index 和新 target 事件驱动同步均已落地；剩余边界是真实业务页面样例，以及浏览器级 target discovery 不可用时的 100ms 轮询兜底提示。
- 完成标准：新标签、iframe、内部滚动容器场景都有明确支持或明确不可支持提示；200 条以上录制列表可流畅使用；单条长录制详情不因全量渲染拖慢页面。
- 依赖关系：需要确认业务中最常见的跨页面/iframe 网站样例和长录制规模。

### 2. 非容器化实例工作台产品化

- 目标：把“外部真实浏览器窗口 + 软件内可视化管理/API 操作/任务编排”作为主线体验。
- 预期产出：实例卡片、状态筛选、当前 URL/标题、截图预览、批量启动/停止/打开 URL/刷新、窗口激活/平铺/主辅排列、任务队列持久化、虚拟滚动和操作记录。
- 进入条件：复用现有 Wails 实例启动、debugPort 和 CDP 能力，不做 WebView2/headless 容器化。
- 完成标准：前端生产构建通过；后端相关测试通过；任务持久化和窗口布局算法有自动测试；真实运行实例可完成导航、刷新、截图预览、窗口激活/排列和批量任务。
- 依赖关系：至少一个可启动的本地浏览器实例；运行中实例 debugPort 就绪。

## Next

### 1. 长录制性能与产品化

- 目标：大量录制和长录制可维护，不拖慢页面。
- 预期产出：list/detail 拆分、搜索 debounce、列表/详情虚拟化或分页、manifest/index、回放进度和失败重试入口。
- 进入条件：真实浏览器基础验收和 P2 状态/接口修复已完成；当前 list/detail、debounce、详情分页、manifest/index、回放进度和失败重试已落地。
- 完成标准：200 条以上录制列表可流畅使用；单条长录制详情按需加载事件。
- 依赖关系：需要确认真实使用中的录制规模和常见筛选方式。

### 3. 外部窗口辅助控制增强

- 目标：在已支持激活、平铺和主辅布局的基础上，提高多屏和恢复场景效率。
- 预期产出：指定屏幕排列、最小化其他窗口、恢复上次布局、窗口截图降级预览。
- 进入条件：实例工作台窗口激活/排列通过真实实例验收。
- 完成标准：窗口控制不改变浏览器 profile、启动参数和窗口顶层身份；失败时不影响 API 操作。
- 依赖关系：Windows-only Win32 窗口管理封装。

### 2. 复杂业务页面回归样例

- 目标：在新 tab/多 page target、same-page iframe 和可连接 OOPIF/CDP iframe 已完成的基础上，用真实业务页面补回归样例。
- 预期产出：内部滚动容器真实页面验收、复杂嵌套 iframe 样例、target discovery 降级到 100ms 轮询时的可复现实例和失败提示。
- 进入条件：真实浏览器基础验收完成。
- 完成标准：真实业务页面中高频内部滚动容器、复杂 iframe 和极早事件场景都有明确支持或明确不可支持提示。
- 依赖关系：需要确认业务中最常见的复杂页面网站样例。

## Later

### 1. 性能、隐私与产品化

- 目标：支持大量录制和长录制，并降低敏感输入风险。
- 预期产出：真实业务页面复杂上下文验收、导入导出/裁剪/回放工具的批量化和文件选择器增强。
- 完成标准：200 条以上录制列表可流畅使用；长录制详情按需加载；敏感字段默认不明文落盘。
- 依赖关系：需要用户确认敏感输入默认策略和真实使用场景。
## 2026-04-29 路线状态更新

- “非容器化实例工作台产品化”的可自动验收闭环已补齐：本地 stop API、workbench HTTP API 和 2 实例真实验收脚本均已落地并跑通。
- 下一阶段重点不再是基础闭环，而是多屏/最小化/布局恢复、预览节流，以及 debugPort 未就绪时的降级预览。
