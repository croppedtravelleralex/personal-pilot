# 浏览器池管理系统设计

> 本文档描述预启动浏览器池 (Browser Pool) 管理系统——保持一定数量的浏览器实例处于预热就绪状态，以消除任务启动延迟。

---

## 0. 术语表

| 术语 | 含义 |
|------|------|
| 池化实例 (Pooled Instance) | 已启动并处于空闲状态的浏览器实例 |
| 预热 (Warm-up) | 提前完成启动、参数注入、路由绑定的操作 |
| 冷启动 (Cold Start) | 从零开始创建 Profile + 启动浏览器的过程 |

## 二、池策略

```go
type PoolPolicy struct {
    MinIdle     int             // 最小保持空闲数（默认 2）
    MaxTotal    int             // 最大总实例数（默认 5）
    WarmUpTime  time.Duration   // 预热超时（默认 30s）
    IdleTTL     time.Duration   // 空闲超时（默认 5min，超时后回收）
    PreWarmOn   []string        // 预热触发条件: startup / event / schedule
    Signature   string          // 池实例统一环境标识
    RoutePoolID string          // 池实例统一路由池
}
```

## 三、生命周期的状态

```
PREHEAT → WARMING → READY → IN_USE → RELEASED → COLD
           ↓                    ↓
        FAILED              STALE → RECYCLE
```

| 状态 | 说明 | 超时 |
|------|------|------|
| `PREHEAT` | 配置已分配，实例未启动 | — |
| `WARMING` | 浏览器正在启动 | 30s → FAILED |
| `READY` | 浏览器已就绪，等待任务 | 5min → STALE |
| `IN_USE` | 被任务占用 | 由任务超时决定 |
| `STALE` | 空闲超时，待回收 | 立即 → RECYCLE |
| `FAILED` | 启动失败，待清除 | 立即 → COLD |

## 四、预热流程

```
1. Pool Engine 判定需要新实例 (count(READY) < MinIdle)
2. 创建新 Profile（使用池化环境标识）
3. 绑定路由节点
4. 启动浏览器 + CDP 连接
5. 注入环境参数脚本
6. 执行 warm-up 页面（打开空白页）
7. 标记为 READY
8. 加入就绪队列（按预热顺序排列）
```

## 五、任务分配

```go
// Acquire 从池中获取空闲实例
// 分配策略:
//   1. 按 FIFO 从 READY 队列取
//   2. 标记为 IN_USE
//   3. 启动任务超时计时器
//   4. 返回控制句柄
//
// Release 将实例归还池中
//   1. 清理会话（Cookie/Storage 清零）
//   2. 导航到空白页
//   3. 标记为 READY
//   4. 重置空闲超时计时器
```

## 六、冷启动 vs 池化启动

| 指标 | 冷启动 | 池化启动 | 优化 |
|------|--------|---------|------|
| Profile 创建 | ~500ms | 0 (预创建) | 无 |
| 路由绑定 | ~200ms | 0 (预绑定) | 无 |
| 浏览器启动 | ~5-15s | 0 (已启动) | 跳过 |
| 环境参数注入 | ~300ms | 0 (已注入) | 跳过 |
| 页面加载 | ~2-5s | ~2-5s | 无 |
| **总耗时** | **~8-21s** | **~2-5s** | **节省 ~75%** |

## 七、API

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/pool/config` | GET/PUT | 池配置读写 |
| `/api/pool/status` | GET | 池状态（各槽位详情） |
| `/api/pool/acquire` | POST | 从池中获取实例 |
| `/api/pool/release` | POST | 归还实例 |
| `/api/pool/metrics` | GET | 命中率/等待时间/回收率统计 |
